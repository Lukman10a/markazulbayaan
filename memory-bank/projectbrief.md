# Project Brief: Markazul Bayaan

## Project Overview
Markazul Bayaan is a comprehensive Islamic education platform built with Next.js, TypeScript, and Tailwind CSS. The project serves as a digital hub for learning Arabic language, Quranic studies, Islamic theology (Tawhid), and related Islamic sciences.

## Core Purpose
To provide an accessible, modern online platform where Muslims worldwide can pursue Islamic knowledge through structured courses, scholarly content, and interactive learning experiences.

## Key Objectives
1. **Educational Excellence**: Deliver high-quality Islamic education courses in Arabic, Quran, Tawhid, Tafsir, Fiqh, and Tajwid
2. **Accessibility**: Make Islamic knowledge accessible to learners of all levels worldwide
3. **Scholarly Approach**: Provide courses taught by qualified instructors following authentic Islamic methodology
4. **Community Building**: Foster a learning community through testimonials, reviews, and engagement
5. **Content Management**: Maintain a blog for scholarly articles and educational content

## Primary Features
- **Course Catalog**: Six comprehensive courses with detailed syllabi and objectives
- **Contact & Enrollment**: Integrated contact forms with EmailJS for inquiries and enrollment
- **Content Management**: Blog system with markdown support and CMS integration
- **User Experience**: Responsive design with animations and modern UI components
- **Reviews & Testimonials**: Social proof through student feedback and testimonials

## Target Audience
- Muslims seeking to deepen their Islamic knowledge
- Students wanting to learn Arabic language for Quranic understanding
- Individuals interested in Islamic theology and jurisprudence
- Learners at all levels (beginner to advanced)

## Technical Stack
- **Framework**: Next.js 14 with TypeScript
- **Styling**: Tailwind CSS with custom components
- **UI Components**: Radix UI primitives with shadcn/ui
- **Animations**: Framer Motion and React Spring
- **Content**: MDX support for blog posts
- **CMS**: Decap CMS (formerly Netlify CMS) for content management
- **Email**: EmailJS for contact form functionality
- **Icons**: Lucide React and React Icons

## Success Metrics
- Course enrollment and completion rates
- User engagement through contact forms and inquiries
- Blog content consumption and sharing
- Positive student testimonials and reviews
- Platform accessibility across devices and browsers

## Project Constraints
- Budget-conscious development approach
- Focus on authentic Islamic scholarship
- Multilingual considerations (Arabic and English)
- Performance optimization for global accessibility
- SEO optimization for educational content discovery
